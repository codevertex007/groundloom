# Cost and capacity management

Attribute model/token/tool/storage/embedding/render cost to workspace/project/run/module and model profile. Configure warning/soft-stop/hard-stop budgets and concurrency limits. A stop produces useful partial state and a resume/approval path where policy allows.

Capacity review monitors queue age, concurrency, context growth, database/object/index size, ingestion/render throughput, and provider quotas. Optimize measured hot paths: retrieval/context bounds, model routing after eval, caching immutable derived results, and targeted rather than full regeneration. Cost reduction cannot bypass quality/security gates.
