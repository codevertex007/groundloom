# Reference material

Files under `ref/` are informative evidence supplied with the project pack. They do not override Groundloom product requirements, accepted ADRs, contracts, or security invariants.

- `deepagents/` contains the verbatim Deep Agents material supplied by the user. Codex must consult the relevant files before implementing framework behavior and must verify current installed APIs when code is written.

If a reference conflicts with a normative Groundloom document, record the conflict and follow the normative document unless an ADR/spec update is approved.
