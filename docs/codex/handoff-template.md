# Codex handoff template

```markdown
## Outcome
What user-visible/system capability now works.

## Requirements satisfied
IDs and acceptance evidence.

## Changes
Code, migration, configuration, docs, ADRs.

## Validation
Commands/tests/evals executed and actual results; skipped checks with reason.

## Architecture/security review
Invariants checked; threat/failure cases considered.

## Deviations and decisions
Approved deviations, new risks/open questions.

## Next safe step
The next incomplete checklist item and prerequisites.
```
